## 1. Pytanie: co robi test „get started link”?

```ts
test('get started link', async ({ page }) => {
  await page.goto('https://playwright.dev/');

  // Click the get started link.
  await page.getByRole('link', { name: 'Get started' }).click();

  // Expects page to have a heading with the name of Installation.
  await expect(page.getByRole('heading', { name: 'Installation' })).toBeVisible();
});
```

Test sprawdza, czy przycisk „Get started” na stronie Playwrighta prowadzi we właściwe miejsce:

1. Otwiera stronę `https://playwright.dev/`.
2. Szuka linku o dostępnej nazwie „Get started” i go klika. `getByRole('link', …)` wyszukuje
   element po roli, tak jak widzi go czytnik ekranu, a nie po selektorze CSS.
3. Sprawdza, czy na stronie, która się otworzyła, widać nagłówek „Installation”. Jeśli nagłówek
   nie pojawi się w domyślnym czasie oczekiwania (5 s), test nie przejdzie.

To przykładowy test, który Playwright generuje przy instalacji (`npm init playwright`). Sprawdza
stronę playwright.dev, a nie własną aplikację, więc można go zastąpić własnymi testami.

## 2. Prośba: nowy test – wejdź na tę samą stronę, kliknij sekcję CLI i przewiń na sam dół

Link **CLI** znajduje się w górnym menu playwright.dev i prowadzi do `/agent-cli/introduction`.

Dodany test:

```ts
test('CLI section scroll to bottom', async ({ page }) => {
  await page.goto('https://playwright.dev/');

  // Click the CLI link in the top navigation.
  await page.getByRole('link', { name: 'CLI', exact: true }).click();
  await expect(page).toHaveURL(/agent-cli/);

  await page.waitForLoadState('load');

  // Scroll to the very bottom of the page (retry in case content is still rendering)
  // and expect the footer to be visible.
  await expect(async () => {
    await page.evaluate(() => window.scrollTo(0, document.documentElement.scrollHeight));
    await expect(page.locator('footer')).toBeInViewport({ timeout: 1000 });
  }).toPass();
});
```

Co robi test:

1. Otwiera `https://playwright.dev/`.
2. Klika link **CLI** w górnym menu i sprawdza, czy adres zawiera `agent-cli`. `exact: true`
   dopasowuje dokładnie słowo „CLI”, a nie inne linki, które je zawierają.
3. Przewija na sam dół strony (`window.scrollTo`) i sprawdza, czy stopka jest widoczna na ekranie.

### Przebieg i poprawka

- Pierwsza wersja (samo `scrollTo` + `toBeInViewport`) przeszła w Chromium i Firefox, ale nie
  przeszła w WebKit: `viewport ratio 0`. Strona przewijała się, zanim w pełni się załadowała,
  więc nie docierała do samego dołu.
- Poprawka: czekanie na `load` oraz ponawianie przewijania i sprawdzania stopki w
  `expect(...).toPass()`.
- Wynik po poprawce: `npx playwright test tests/prod-tests.spec.ts -g "CLI section" --repeat-each=3`
  – **9/9 przeszło** (Chromium, Firefox, WebKit, po 3 razy).
